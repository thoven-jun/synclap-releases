# SynClap

여러 카메라와 녹음기 파일을 소리로 자동으로 맞춰 주는 Adobe Premiere Pro 패널이에요. 무료로 쓸 수 있고, 대가를 받는 작업에 써도 돼요.

**[최신 버전 받기](https://github.com/thoven-jun/synclap-releases/releases/latest)**

## 할 수 있는 일

- 시퀀스에 올린 카메라와 녹음기 클립을 소리로 찾아 시간을 맞춰요.
- 어느 클립이 맞춰졌고 어느 클립이 안 맞았는지 결과를 보여 줘요.
- 시간이 지나며 조금씩 어긋나는 녹음 파일의 속도를 보정해요. (고급 설정에서 켜고 끌 수 있어요)
- 멀티캠 편집용 시퀀스도 만들 수 있어요.

소리가 없는 클립이나 같은 소리가 녹음되지 않은 클립은 맞출 수 없어요. 결과는 꼭 직접 확인해 주세요.

## 받을 파일

[릴리스 페이지](https://github.com/thoven-jun/synclap-releases/releases/latest)의 Assets에서 내 컴퓨터에 맞는 파일 하나만 받으면 돼요.

| 컴퓨터 | 파일 |
|---|---|
| 맥 (Apple 칩 / Intel) | `SynClap-버전-mac.pkg` |
| Windows 10 / 11 (64비트) | `SynClap-버전-win-Setup.exe` |

`Source code`라고 적힌 압축 파일은 받지 않아도 돼요. GitHub가 자동으로 붙이는 항목이고, 앱이 들어 있지 않아요.

Premiere Pro 2020(14.0) 이상에서 열리도록 만들었어요. 다만 테스트는 Premiere Pro 2026에서만 했어요.

## 설치하기

관리자 암호(권한)는 필요 없어요. 앱에 유료 인증을 받지 않아서 처음 열 때 경고가 나와요.

**맥**

1. `.pkg` 파일을 더블클릭해요. "열 수 없다"는 창이 나오면 '휴지통으로 이동'은 누르지 말고 '완료'를 눌러요.
2. 시스템 설정 > 개인정보 보호 및 보안으로 가서 아래로 내린 뒤, 차단되었다는 줄 옆의 '그래도 열기'를 눌러요.
3. 다시 확인창이 나오면 '그래도 열기'를 누르고, 맥 암호나 지문을 물으면 입력해요.
4. 설치 화면을 따라 사용 조건에 동의하고 설치해요.

**Windows**

1. `Setup.exe` 파일을 더블클릭해요.
2. 파란 "Windows의 PC 보호" 창이 나오면 '추가 정보'를 누른 다음 '실행'을 눌러요.
3. 설치 화면을 따라 사용 조건에 동의하고 설치해요.

## 사용하기

1. Premiere Pro를 켜요. 켜져 있었다면 껐다가 다시 켜요.
2. 위쪽 메뉴에서 `창 > 확장 > SynClap`을 열어요.
3. ffmpeg가 없으면 패널의 안내를 따라 설치해요. ffmpeg는 소리를 읽는 데 쓰는 별도의 무료 프로그램이에요.

새 버전은 자동으로 받아 두고, 패널을 다시 열 때 적용해요.

## 문제가 있을 때

패널의 톱니바퀴 `고급 설정`에서 `문제 보고하기`를 눌러 주세요. 보내기 전에 보낼 내용을 먼저 보여 드려요. 개별 답변이나 기술 지원은 약속드리지 못해요.

## 개인 정보

- 영상과 소리는 어디로도 보내지 않아요. 싱크는 내 컴퓨터 안에서 처리해요.
- **업데이트 확인:** 새 버전을 확인하려고 GitHub에 접속해요.
- **ffmpeg 자동 설치:** 파일을 제공하는 외부 사이트에 접속해요.
- **문제 보고:** '보내기'를 누른 경우에만 앱·Premiere 버전, 컴퓨터 종류, 싱크 결과 요약, 작업 기록, 클립 파일 이름, 적어 주신 메모를 보내요. 폴더 경로와 계정 이름은 가리고, Cloudflare와 Discord를 거쳐 전달돼요.

## 제거하기

Premiere Pro를 끄고 아래 중 하나로 제거해요.

- 패널의 `고급 설정`에서 `제거 프로그램 열기`를 눌러요.
- 맥: 홈 폴더 안 Applications 폴더의 `SynClap 제거`를 열어요.
- Windows: 설정 > 앱 > 설치된 앱에서 `SynClap`을 제거해요.
